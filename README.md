# Neo-Brutalism Web Calculator

A simple, responsive web-based calculator featuring a clean, high-contrast neo-brutalist design aesthetic. 

## ✨ Features

*   **Core Arithmetic:** Supports basic math operations (addition, subtraction, multiplication, division).
*   **Distinct UI:** Designed with a neo-brutalist style utilizing stark black-and-white contrast, bold borders, and sharp solid drop shadows.
*   **Mobile-First Design:** Fully responsive and optimized for mobile browser displays.
*   **Essential Controls:** Includes standard Clear (`C`), Backspace (`⌫`), and Decimal (`.`) functionality.

## 🚀 Technologies Used

*   **HTML5:** Semantic structure for the calculator grid and display.
*   **CSS3:** Styling for the unique high-contrast UI, grid layouts, and shadow effects.
*   **JavaScript (Vanilla):** Core calculation logic and DOM manipulation.
